# Security Policy

Markdown to TXT processes user-provided text and local files inside the browser.

## Reporting

If this project is hosted on GitHub, use GitHub Security Advisories when available. Otherwise, contact the maintainer directly.

Please include:

- Browser and operating system.
- Minimal Markdown input that reproduces the issue.
- Whether clipboard or file drag-and-drop is involved.

## Security expectations

- No network request is required for normal conversion.
- No content is uploaded.
- No scripts embedded in Markdown should be executed.
- File handling is limited to files selected or dropped by the user.
