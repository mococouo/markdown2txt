==== Markdown 转 TXT - 本地使用说明 ====

【快速开始】
1. 解压文件夹
2. 双击 index.html
3. 默认界面为英文，可在右上角 Language 切换为中文
4. 在浏览器中开始使用

【文件说明】
- index.html  主页面
- styles.css  样式文件
- script.js   转换和交互逻辑

【常用操作】
1. 输入内容
   - 直接粘贴 Markdown
   - 点击“粘贴”
   - 点击“打开文件”
   - 拖入一个或多个 .md / .markdown / .txt 文件

2. 选择转换样式
   - 标准：适合日常转换
   - 纯净：输出更干净的正文
   - 结构化：保留标题、列表、代码块边界

3. 调整输出规则
   - 保留链接地址
   - 保留代码块内容
   - 移除 front matter
   - 输入时自动转换

4. 导出结果
   - 复制结果
   - 下载当前文件
   - 批量文件可合并下载全部结果

【隐私说明】
本工具完全在浏览器本地运行，不上传文件，不保存内容，不需要联网。

【提示】
如果浏览器限制剪贴板权限，可直接在输入框中使用 Ctrl+V，在输出框中手动复制。
