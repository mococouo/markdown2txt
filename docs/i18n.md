# Internationalization

The app uses a small built-in i18n layer in `script.js`.

This keeps the project:

- static
- dependency-free
- usable by directly opening `index.html`
- compatible with GitHub Pages

## Adding a language

1. Add the language to `languageMeta`.
2. Add translations to `translations`.
3. Use `withFallback(...)` so missing strings fall back to English.
4. For right-to-left languages, set `dir: "rtl"`.
5. Manually check layout in the browser.
