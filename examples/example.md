# Markdown示例文档

这是一个用于测试 **Markdown转TXT工具** 的示例文档。

## 格式展示

### 1. 文本格式

普通文本不会有任何特殊格式。

*斜体文本* 和 **粗体文本** 以及 ***粗斜体*** 在转换后会有不同表现。

~~删除线~~ 也是一种常见的格式。

### 2. 列表

无序列表：

* 第一项
* 第二项
* 第三项

有序列表：

1. 第一步
2. 第二步
3. 第三步

### 3. 引用

> 这是一段引用的文字。
> 
> 这是引用的第二段落。

### 4. 代码

行内代码: `print("Hello World")`

代码块：

```python
def hello_world():
    print("Hello, World!")
    return True
    
hello_world()
```
